Frequently asked questions about FedEx quotes

Welcome to the QuickQuoteTool FAQ. Here you’ll find answers to the most common questions about using our tool to generate instant FedEx quotes.

How do I get a FedEx quote online?

Enter your shipment details (origin, destination, weight, dimensions) in QuickQuoteTool to get an instant FedEx quote.

Is QuickQuoteTool an official FedEx service?

No. QuickQuoteTool is an independent tool that uses the official FedEx API to calculate shipping rates, but it is not affiliated with FedEx.

Are the displayed rates reliable?

Yes. Rates are calculated from the FedEx API. They provide a precise estimate, subject to final conditions applied by FedEx.

Do I need to create an account to use the tool?

No. No account is required to get a quote. However, to use your negotiated discounts, you should use your own FedEx account number.

Are my shipment details stored?

No. The information you enter is only used to generate the quote and is not stored.

Where are my personal presets saved?

Personal presets are stored locally in your browser. This design avoids conflicts when multiple users share the same FedEx account number. Each user can therefore create and manage their own presets independently.

How do I add a personal preset?

To add a personal (custom) preset:

  • Enter your package dimensions and weight.
  • Click Add custom package in the predefined package section.
  • The preset is automatically saved in your browser for the currently entered FedEx account number.
  • You can reuse it instantly from My presets for future quotes.

Can I use QuickQuoteTool for my company?

Yes. The tool is designed for SMEs, businesses and logistics professionals who want to obtain FedEx rates quickly.

What types of shipments are supported?

QuickQuoteTool supports domestic, cross-border and international shipments depending on available FedEx services.

Note: QuickQuoteTool is an independent tool using the FedEx API. It is not affiliated with FedEx.

Preguntas frecuentes sobre las cotizaciones FedEx

Bienvenido a la sección de preguntas frecuentes de QuickQuoteTool. Aquí encontrarás respuestas a las preguntas más comunes sobre el uso de nuestra herramienta para obtener cotizaciones FedEx instantáneas.

¿Cómo obtener una cotización FedEx en línea?

Ingresa los datos de tu envío (origen, destino, peso, dimensiones) en QuickQuoteTool para obtener una cotización FedEx instantánea.

¿QuickQuoteTool es un servicio oficial de FedEx?

No. QuickQuoteTool es una herramienta independiente que utiliza la API oficial de FedEx para calcular tarifas de envío, pero no está afiliada a FedEx.

¿Las tarifas mostradas son confiables?

Sí. Las tarifas se calculan a partir de la API de FedEx. Son una estimación precisa, sujeta a las condiciones finales aplicadas por FedEx.

¿Debo crear una cuenta para usar la herramienta?

No. No se requiere crear una cuenta para obtener una cotización. Para usar tus descuentos o tarifas negociadas, debes usar tu propio número de cuenta FedEx.

¿Se guardan mis datos de envío?

No. Los datos ingresados se usan únicamente para generar la cotización y no se almacenan.

¿Dónde se guardan mis paquetes personalizados?

Los paquetes personalizados se guardan localmente en tu navegador. Este diseño evita conflictos cuando varios usuarios comparten el mismo número de cuenta FedEx. Cada usuario puede crear y gestionar sus propios paquetes de forma independiente.

¿Cómo agrego un paquete personalizado?

Para agregar un paquete personalizado:

  • Ingresa las dimensiones y el peso del paquete.
  • Haz clic en Agregar paquete personalizado en la sección de paquetes predefinidos.
  • El paquete se guarda automáticamente en tu navegador para el número de cuenta FedEx ingresado.
  • Podrás reutilizarlo inmediatamente desde Mis paquetes.

¿Puedo usar QuickQuoteTool para mi empresa?

Sí. La herramienta está pensada para pymes, empresas y profesionales de logística que desean obtener tarifas FedEx rápidamente.

¿Qué tipos de envíos están soportados?

QuickQuoteTool soporta envíos nacionales, transfronterizos e internacionales según los servicios FedEx disponibles.

Nota: QuickQuoteTool es una herramienta independiente que utiliza la API de FedEx. No está afiliada a FedEx.

¿Dónde se guardan mis preajustes personales?

Los preajustes personales se guardan localmente en tu navegador para evitar conflictos cuando varios usuarios comparten el mismo número de cuenta FedEx. Por lo tanto, cada usuario puede crear y administrar sus propios preajustes de forma independiente.

¿Cómo agrego un preajuste personal?

Para agregar un preajuste personal:

  • Ingresa las dimensiones y el peso del paquete.
  • Haz clic en Agregar paquete personalizado en la sección de paquetes predefinidos.
  • El preajuste se guarda automáticamente en tu navegador para el número de cuenta FedEx ingresado.
  • Puedes reutilizarlo de inmediato desde Mis preajustes en futuras cotizaciones.

Häufige Fragen zu FedEx-Angeboten

Willkommen im QuickQuoteTool-FAQ. Hier finden Sie Antworten auf die häufigsten Fragen zur Nutzung unseres Tools für sofortige FedEx-Angebote.

Wie erhalte ich online ein FedEx-Angebot?

Geben Sie Ihre Sendungsdaten (Absender, Empfänger, Gewicht, Maße) in QuickQuoteTool ein, um ein sofortiges FedEx-Angebot zu erhalten.

Ist QuickQuoteTool ein offizieller FedEx-Service?

Nein. QuickQuoteTool ist ein unabhängiges Tool, das die offizielle FedEx-API nutzt, ist aber nicht mit FedEx verbunden.

Sind die angezeigten Preise zuverlässig?

Ja. Die Preise werden über die FedEx-API berechnet und sind eine genaue Schätzung, vorbehaltlich der finalen Bedingungen von FedEx.

Muss ich ein Konto erstellen, um das Tool zu nutzen?

Nein. Für ein Angebot ist kein Konto erforderlich. Für verhandelte Rabatte sollten Sie Ihre eigene FedEx-Kontonummer verwenden.

Werden meine Versanddaten gespeichert?

Nein. Die eingegebenen Daten werden nur zur Angebotserstellung verwendet und nicht gespeichert.

Wo werden meine persönlichen Paketvorlagen gespeichert?

Persönliche Paketvorlagen werden lokal im Browser gespeichert. Dieses Design vermeidet Konflikte, wenn mehrere Nutzer dieselbe FedEx-Kontonummer verwenden. Jeder Nutzer kann seine eigenen Vorlagen unabhängig verwalten.

Wie füge ich eine persönliche Paketvorlage hinzu?

So fügen Sie eine persönliche Paketvorlage hinzu:

  • Geben Sie Abmessungen und Gewicht des Pakets ein.
  • Klicken Sie im Bereich der vordefinierten Pakete auf Benutzerdefiniertes Paket hinzufügen.
  • Die Vorlage wird automatisch im Browser für die eingegebene FedEx-Kontonummer gespeichert.
  • Sie können sie sofort unter Meine Vorlagen wiederverwenden.

Kann ich QuickQuoteTool für mein Unternehmen nutzen?

Ja. Das Tool ist für KMU, Unternehmen und Logistikprofis geeignet, die schnell FedEx-Preise benötigen.

Welche Sendungen werden unterstützt?

QuickQuoteTool unterstützt nationale, grenzüberschreitende und internationale Sendungen – abhängig von den verfügbaren FedEx-Services.

Hinweis: QuickQuoteTool ist ein unabhängiges Tool, das die FedEx-API nutzt. Es ist nicht mit FedEx verbunden.

Questions fréquentes sur les soumissions FedEx

Bienvenue dans la section FAQ de QuickQuoteTool. Ici, vous trouverez des réponses aux questions les plus courantes concernant l’utilisation de notre outil pour obtenir des soumissions FedEx instantanées.

Comment obtenir une soumission FedEx en ligne ?

Il suffit d’entrer les informations de votre expédition (origine, destination, poids, dimensions) dans QuickQuoteTool pour obtenir une soumission FedEx instantanée.

QuickQuoteTool est-il un service officiel FedEx ?

Non. QuickQuoteTool est un outil indépendant qui utilise l’API officielle FedEx pour calculer les tarifs d’expédition, mais il n’est pas affilié à FedEx.

Les tarifs affichés sont-ils fiables ?

Oui. Les tarifs sont calculés à partir des données fournies par l’API FedEx. Ils constituent une estimation précise, sous réserve des conditions finales appliquées par FedEx.

Dois-je créer un compte pour utiliser l’outil ?

Non. Aucune création de compte n’est requise pour obtenir une soumission FedEx avec QuickQuoteTool. Pour utiliser l’outil avec vos rabais ou tarifs négociés, vous devez utiliser votre propre numéro de compte FedEx.

Mes données d’expédition sont-elles sauvegardées ?

Non. Les données saisies servent uniquement à générer la soumission et ne sont pas stockées.

Où sont enregistrés mes colis personnalisés ?

Les colis personnalisés sont enregistrés localement dans votre navigateur. Ce choix permet d’éviter les conflits lorsque plusieurs utilisateurs partagent le même numéro de compte FedEx. Chaque utilisateur peut ainsi gérer ses propres colis de manière indépendante.

Comment ajouter un colis personnalisé ?

Pour ajouter un colis personnalisé :

  • Entrez les dimensions et le poids du colis.
  • Cliquez sur Ajouter un colis personnalisé dans la section des colis prédéfinis.
  • Le colis est automatiquement sauvegardé dans votre navigateur pour le numéro de compte FedEx utilisé.
  • Il sera immédiatement disponible dans Mes colis pour vos prochaines soumissions.

Puis-je utiliser QuickQuoteTool pour mon entreprise ?

Oui. L’outil est conçu pour les PME, entreprises et professionnels de la logistique qui souhaitent obtenir rapidement des tarifs d’expédition FedEx.

Quels types d’expéditions sont supportés ?

QuickQuoteTool supporte les expéditions domestiques, transfrontalières et internationales selon les services FedEx disponibles.

Note: QuickQuoteTool est un outil indépendant utilisant l’API FedEx. Il n’est pas affilié à FedEx.
